# Fleet Desk
Vans, routes, drivers, daily km, fines and documents in one place.

## Get the APK (no installs needed on your computer)
1. Create a free GitHub account and a new repository.
2. Upload everything in this folder (keep the .github folder).
3. Open the Actions tab -> "Build APK" -> wait ~5 min.
4. Download `fleet-desk-apk` from the finished run, unzip, and install app-debug.apk on your phone.

## Quick try
Host the `www` folder anywhere (e.g. Netlify drop), open on Android Chrome -> menu -> Install app.
